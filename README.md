## The word

**Contraption**

Eleven characters, one word, nothing else. It is the word a grandma would text about AI: the warm, slightly baffled name she gives a machine she does not understand. Every grandma has called some new gadget a contraption. It is funny on its own, tied to machines, fresh, and instantly readable.

## How it works

`main.py` (Python 3, standard library only) writes exactly `Contraption` to `/output/entry.txt` and prints it. No input, no randomness, no network, no clock. Two runs produce byte identical output.
